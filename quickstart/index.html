Gemini 3.6 Flash APIはどのように呼び出しますか？

変更するのは2つの変数です。base_urlはゲートウェイを指し、api_keyは発行されたトークンに置き換えます。それ以外は何も変更しません。

  1. 現在の料金情報を確認する：料金エンドポイントを取得し、利用料金を見積もる前にgemini-3.6-flashが掲載されていることを確認します。
  2. グループ倍率を確認する：最終料金は基本料金にその値を乗じて算出されるため、自分のグループに割り当てられた倍率を確認します。
  3. 利用料金を見積もる：入力トークンと出力トークンを分けて見積もり、それぞれの基本料金にグループ倍率を適用します。
  4. 統合時の動作を確認する：デプロイ前に、仲介サービスのドキュメントで現在のエンドポイント、認証方式、リクエストスキーマ、サポートされている機能を確認します。

完全なコード例

import json
from urllib.request import urlopen

# Fetch the pricing payload published by the panel.
url = "https://api.openlux.ai/api/pricing"
with urlopen(url, timeout=30) as response:
    payload = json.load(response)

# Save the raw response so its current schema can be inspected safely.
with open("pricing.json", "w", encoding="utf-8") as output:
    json.dump(payload, output, ensure_ascii=False, indent=2)

print("Saved the current pricing payload to pricing.json")
print("Search the file for: gemini-3.6-flash")
